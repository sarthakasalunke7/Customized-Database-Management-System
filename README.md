# Customized-Database-Management-System
A simple in-memory Database Management System (DBMS) implemented in Java for managing employee records. Supports basic SQL-like operations and aggregate functions.
This project implements a custom, in-memory Database Management System (DBMS) in Java. 
It allows users to store, retrieve, and manipulate employee records using a menu-driven interface.

## Features

- Insert new employee records (Name, Address, Salary)
- Display all records or specific records by EID or Name
- Delete records by EID or Name
- Aggregate functions:
  - Sum of salaries
  - Average salary
  - Minimum and Maximum salary
  - Count of employees
- User-friendly console menu
